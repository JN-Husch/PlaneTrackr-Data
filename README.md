# PlaneTrackr 2 — downloads and data

This repository hosts the official builds of **PlaneTrackr 2** and the data files the app downloads.
It contains no source code. PlaneTrackr is freeware, but not open source.

Website, help and download page: https://jn-husch.com/projects/software/planetrackr-download/

## Downloads (always the newest version)

| System | File |
|---|---|
| Windows 10 / 11 (portable, no installer) | [PlaneTrackr2.exe](https://github.com/JN-Husch/PlaneTrackr-Data/releases/download/app/PlaneTrackr2.exe) |
| macOS (Apple Silicon and Intel) | [PlaneTrackr2-macOS.dmg](https://github.com/JN-Husch/PlaneTrackr-Data/releases/download/app/PlaneTrackr2-macOS.dmg) |
| Linux (x86-64 AppImage) | [PlaneTrackr2-Linux-x86_64.AppImage](https://github.com/JN-Husch/PlaneTrackr-Data/releases/download/app/PlaneTrackr2-Linux-x86_64.AppImage) |

PlaneTrackr checks for updates at every start and installs them after you agree.
Older versions: see [Releases](https://github.com/JN-Husch/PlaneTrackr-Data/releases).

- **Windows:** at the first start, SmartScreen may show "Windows protected your PC" → *More info* → *Run anyway*.
- **macOS:** move PlaneTrackr 2 to the Applications folder before the first start, so updates can be installed.
- **Linux:** make the AppImage executable once (`chmod +x PlaneTrackr2-Linux-x86_64.AppImage`).

## Data files

The release **airspaces** contains the world-wide airspace file used by PlaneTrackr 2, updated monthly.
Airspace data © [openAIP](https://www.openaip.net), licensed under [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/).
